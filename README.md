# CTSS: Category Theory Summarizer Skill

**
给定单一范畴论骨架的材料总结提示词，当前以agent转为skill迭代至0.2.2版本（见"ai example"文件夹），在人工参考修改中，正式release版完成时将重新发布。
**

注：本示例为IVM/MVI双向循环认知假设中Model部分自上而下的简单实验用例，本意是为了基于材料生成一个无问题导向的图，并在下一步Value模块中基于后续问题材料用于生成skill类。
把范畴论想成“逻辑系统的逻辑”：逻辑里最核心的是“从前提推出结论”，范畴论则把这种“推出”变成箭头来研究。
所以，范畴论用逻辑学通俗地说，就是：**把“证明”当作箭头，把“逻辑系统”当作箭头组成的网，然后研究这些网如何翻译、比较、构造、配对、包装，以及如何由关系决定对象。**

下面逐项用逻辑学来通俗解读示例中的骨架：
示例范畴论骨架：
   - 范畴 C：对象 Ob(C)、态射 Hom(C)、复合 ∘、恒等 id
   - 函子 F: C → D
   - 自然变换 η: F ⇒ G
   - 极限/余极限、伴随、单子、Yoneda（若适用）

| 范畴论 | 逻辑学通俗解释 |
|---|---|
| 对象 \(Ob(C)\) | 命题、类型、上下文 |
| 态射 \(Hom(A,B)\) | 从 A 推出 B 的证明/推导 |
| 复合 \(g\circ f\) | 证明串接：A 推出 B，B 推出 C，所以 A 推出 C |
| 恒等 \(id_A\) | 平凡证明：A 推出 A |
| 函子 \(F:C\to D\) | 两个逻辑系统之间的翻译：把命题翻译成命题，把证明翻译成证明，并保持推理链 |
| 自然变换 \(\eta:F\Rightarrow G\) | 两种翻译之间的“翻译证明”：对每个命题 A，给一个证明 \(F(A)\to G(A)\)，且与推理相容 |
| 极限 | 偏“合取/同时满足/约束”：积像 \(A\land B\)，终对象像“真” |
| 余极限 | 偏“析取/至少一个/粘合”：余积像 \(A\lor B\)，初始对象像“假” |
| 伴随 \(F\dashv G\) | 引入规则与消去规则的配对，像量词、蕴词、柯里化 |
| 单子 | 给证明加一层“效果/模态/计算包装” |
| Yoneda | 一个命题/对象由它与其他命题/对象的证明关系完全决定 |
