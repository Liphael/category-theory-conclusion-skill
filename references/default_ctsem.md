## step_2: 检测文本类型与形式化程度

**要回答的四个问题**

| 问题 | 常见取值 | 为什么重要 |
| --- | --- | --- |
| 文本类型有什么？ | 教学讲义 / 论文 / 教材 / 技术文档 / 规格说明 / 博客 / 访谈 | 决定"显式结构"的密度预期 |
| 专业领域有什么？ | 统计、机器学习、物理、编程、哲学、生物…… | 决定骨架切入点（见骨架指南） |
| 形式化程度多高？ | 高（公理—定理—证明）／中（定义—例子）／低（叙述性） | **注意**：形式化语言的强弱 ≠ 可范畴化的强弱 |
| 范畴论含量多高？ | 字面 0% 到 100% | 决定本任务是「转写型」还是「重构型」 |

**关键判据**：绝大多数应用类文本是**「语言形式化低、结构可范畴化高」**。
判定它是重构型任务而非转写型任务，是整个流程的起点——这决定了步骤 4 的工作量有多大，也决定了置信度标注必须做细。

**做完的标志**：一张 4 行的判断表，每行有出处（页码 / 章节）。

## step_3: extract / reconstruct category theory structure

依序执行以下流程，**禁止跨步骤生成“高阶结构”**：

### phase_0.1

识别文本中所有“候选目标”，记为“候选目标 Candi_Tar(C)”，包括但不限于：
    - 类型、集合、空间、群、命题、状态、模型、对象实例；
    - 函数、映射、同态、连续映射、关系、过程、迁移、更新、证明、管道；
    - 复合：∘、串联、依赖、then、bind、管道 |>；
    - 恒等：id、恒等映射、空操作、单位元、反射、不变；  恒等候选： id 、恒- 等映射、空操作、单位元
    - 高阶结构：函子、自然变换、极限、余极限、伴随、单子、Yoneda、可表、泛性质。

输出：“候选目标集合G”，集合中每个候选目标暂时没有固定标签。

### phase_0.2

识别文本中所有“候选箭头”，记为“候选箭头 Candi_Arw(C)”，包括但不限于：
    - 函数、映射、过程、迁移、关系、更新；
    - 复合运算、管道、绑定、串联；
    - 有方向性的依赖或转换。

给予标签：“候选箭头”。

### phase_0.3

对每个候选目标，识别多标签角色：
    识别“候选对象 Candi_Ob(C)”：作为箭头源/靶、有恒等候选、作为类型/集合/空间/状态、参与复合端点;
    识别“候选态射 Candi_Hom(C)”：有明确源靶、可复合、有恒等候选;
    识别多重标签，添加多标签标记;

**“候选对象 Candi_Ob(C)”与“候选态射 Candi_Hom(C)”标签不是互斥的。**

### phase_0.4

抽取并标注：
    - 复合：$g\circ f$、串联、依赖、then、bind
    - 恒等操作：$id_X$、空操作、单位元、反射

检查候选：
    - 复合是否闭合
    - 恒等是否单位
    - 复合是否结合

### phase_0.5

对候选目标继续识别高阶结构：
    候选函子
    候选自然变换
    候选极限
    候选余极限
    候选伴随
    候选单子
    候选Yoneda单子。

**对于每个高阶结构，计算其依赖**

### phase_0.6

对暂未分配标签的“候选目标”，标记为“背景项”
