# 五步模型 · 逐步展开

> 本文把 SKILL.md 的步骤 1–5 展开为可执行动作与判据。
> 每一步都有「做完的标志」，做不到的不要跳过，落到「信息缺失」。

---

## 步骤 1：判断文本类型与形式化程度

**要回答的四个问题**

| 问题 | 常见取值 | 为什么重要 |
| --- | --- | --- |
| 文本类型是什么？ | 教学讲义 / 论文 / 教材 / 技术文档 / 规格说明 / 博客 / 访谈 | 决定"显式结构"的密度预期 |
| 学科域是什么？ | 统计、机器学习、物理、编程、哲学、生物…… | 决定骨架切入点（见骨架指南） |
| 形式化程度多高？ | 高（公理—定理—证明）／中（定义—例子）／低（叙述性） | **注意**：形式化语言的强弱 ≠ 可范畴化的强弱 |
| 范畴论含量多少？ | 字面 0% 到 100% | 决定本任务是「转写型」还是「重构型」 |

**关键判据**：绝大多数应用类文本是**「语言形式化低、结构可范畴化高」**。
判定它是重构型任务而非转写型任务，是整个流程的起点——这决定了步骤 3 的工作量有多大，也决定了置信度标注必须做细。

**做完的标志**：一张 4 行的判断表，每行有出处（页码 / 章节）。

---

## 步骤 2：抽取 / 重构范畴骨架

按下面顺序找，找到一条记一条，**不要跳到"高阶结构"去**——伴随、单子都是从"有对象、有态射、能复合"长出来的。

```
对象 Ob(C)  →  态射 Hom(C)  →  复合 ∘ 与恒等 id  →  函子 F: C → D
           →  自然变换 η: F ⇒ G  →  极限 / 余极限  →  伴随  →  单子  →  Yoneda
```

**每一层要记什么**

| 层 | 记录内容 | 最少条数 |
| --- | --- | --- |
| 对象 | ID、含义、出处、显式性、置信度 | 8 条以上（含「信息缺失」这个特殊对象） |
| 态射 | 记号、定义域→值域、出处、显式性、置信度 | 12 条以上 |
| 复合 | 主线复合是什么、哪条交换图在陈述它 | 1 条主线 |
| 恒等 | 哪个性质在说"复合 = id" | 至少 1 处 |
| 函子 | 源范畴 → 目标范畴 | 3 个以上 |
| 自然变换 | 分量、源函子、目标函子 | 2 个以上 |
| 极限/余极限 | 类型 + 实例 + 出处 | 5 种以上 |
| 伴随 | **必须标注层级**（见下） | 3 对以上 |
| 单子 | 单位 η、乘法 μ、代数映射 | 1 个（若能找到） |
| Yoneda | 若适用则写；不适用要**说明为什么不适用** | — |

**伴随必须标层级**（这是最常见的过度声称）：

| 层级 | 含义 | 例子 |
| --- | --- | --- |
| `Cat` 严格 | 普通范畴间的伴随函子对 | Free ⊣ Forgetful；Kleisli 伴随 |
| `Pos` 严格 | 偏序集范畴间的 Galois 连接 | 置信集 ⊣ 接受域 |
| dagger | dagger 范畴中的伴随态射（非普通 Cat 伴随） | Hilbert 空间中 f ⊣ f† |
| 类比 | 只是"看起来像" | **必须显式标注为类比，不能混进上面三档** |

**做完的标志**：骨架清单齐全，且**每条都能指回材料的一处具体位置**；指不回的就是重构，进步骤 3 标注。

---

## 步骤 3：区分「原文显式」与「合理重构」

这是本模型**最核心、也最容易被偷懒跳过**的一步。

**三档标注（每档都要给，不能只给一档）**

| 档 | 定义 | 判据 |
| --- | --- | --- |
| 【显式】 | 材料自己用文字说出来了（含等价说法） | 能引到具体页码/章节 |
| 【半显式】 | 公式/记号给了，但语义没点明 | 公式在，解读不在 |
| 【重构】 | 材料只隐含，是我补的 | 引不到文字，只能靠结构推 |

**置信度星级**（给重构条目）

| 星级 | 含义 |
| --- | --- |
| ★★★★★ | 严格数学对应，文献可查 |
| ★★★★☆ | 严格，但依赖本总结选定的基范畴 |
| ★★★☆☆ | 合理的结构推广，依赖自建范畴结构 |
| ★★☆☆☆ | 启发式类比 |

**常见偷懒形态**（自查）：

- 整份报告通篇没有任何显式性标注 → 不合格
- 只在"找不到的"条目上标重构，"找得到的"不标 → 不合格，两档都要标
- 把类比当严格伴随写 → 不合格，必须降级标注

**做完的标志**：对象表与态射表各有「显式性」与「置信度」两列，且两种标注在全文出现 ≥4 处（门禁会数）。

---

## 步骤 4：不足则检索补足；仍不足则标记「信息缺失」

**顺序不能反**：先检索，后认输。

1. 判断"是否足以构成范畴"：有对象层、有态射层、有复合与恒等 → 足以构成
2. 若不足以构成 → 检索（教科书、综述、nLab、原始论文）补足
3. 检索后仍不足 → 写入对象「信息缺失」表

**「信息缺失」表必须有四列**

| 列 | 内容 |
| --- | --- |
| 缺失结构 | 缺的是什么 |
| 骨架为何需要它 | 不补上，哪条结论立不住 |
| 缺失原因 | 课程有意裁剪？层级所限？材料范围？ |
| 可否外部补足 | 可以 / 不可补足（如层级所限） |

**做完的标志**：「信息缺失」至少有 3 条，且每条都有原因（不能只写"未涉及"）。

---

## 步骤 5：输出五件套

| 件套 | 要求 |
| --- | --- |
| 对象表 | ID / 对象 / 含义 / 出处 / 显式性 / 置信度；含「信息缺失」行 |
| 态射表 | 态射 / 类型 / 出处 / 显式性 / 置信度；按层分组（概率层、推断层、线性层、决策层） |
| 交换图 | 至少 1 个 Mermaid；或明确标注的文字交换图 |
| 范畴论重述 | **3–5 句**，编号列出。每句要能独立成立 |
| 通俗摘要 | 完全不用范畴论术语，让非专业读者能读懂材料本身讲了什么 |

**通俗摘要的额外要求**：按材料的**原始章节顺序**组织，并在末尾给 1–2 条"贯穿暗线"——把分散在各章的同一件事点出来。这一步是范畴化收益的兑现点，不要省。

**做完的标志**：五件套齐全，且通俗摘要里**不出现**「范畴」「态射」「函子」「单子」等术语。

## 迭代（步骤 6）细则

每轮都是**从头重写**，不是打补丁。轮次推进靠上一轮末尾的「本轮自评」：

```
本轮自评：
  ✅ 新增：<本轮新做的东西>
  ⚠️ 仍待处理：<还差什么，逐条列出>
  ➡️ 下一轮目标：<下一轮要补什么>
```

**三轮的典型分工**（可作为默认节奏）：

| 轮 | 定位 | 典型增量 |
| --- | --- | --- |
| R1 | 保守基线 | 显式结构优先，最小重构；定出基范畴与主线复合 |
| R2 | 补结构层 | 高阶结构：函子对、自然变换、极限/余极限盘点、代数结构 |
| R3 | 补严格性与统一性 | 伴随的严格层级、定律与材料计算对账、跨章节统一、置信度评级 |
| R4 | 收敛 | 概念速查表、可证伪性分析、统一总图、四轮演化记录 |
