# 产物设计画像（Artifact Design Profile）

> yao-meta-skill Phase 5.6。本技能的产物是**给同行复核用的分析报告**，不是演示稿、不是看板。
> 设计方向必须由产物用途推出：高可信报告 → 克制的编辑式排版、强层级、紧凑证据块。

## 产物类型与路由

| 产物 | 类型 | 设计方向 | 不该做成 |
| --- | --- | --- | --- |
| `R1..R4_*.md` | 高可信分析报告 | 编辑式排版；标题即结论；表优先于段落 | 卡片网格、渐变、装饰性分隔线 |
| `00_INDEX.md` | 导航 + 收敛结论 | 一屏可扫完；链接真实存在 | 长篇复述各轮内容 |
| `manifest.json` | 机器读的中间产物 | 平铺字段，无嵌套 | 人读的说明文档 |

## 视觉/排版方向（由内容推出，非沿用模板）

- **层级靠标题，不靠字号**。报告有「对象表 / 态射表 / 交换图 / 重述 / 摘要」五层，用 `##` / `###` 区分即可，不额外做样式。
- **表格只在「比较」是主要工作时才用**。本技能恰好有两个天生表格（对象表、态射表），其余一律用段落或列表。
- **公式与术语不打断阅读**：`$\mathbb{E}$` 这类行内公式可以直接写；大段推导一律移出正文，放附录或不写。
- **出处用行内小字**，不放脚注区，避免阅读跳转。
- **窄宽可读**：表格列数控制在 ≤6 列，超宽表格在手机端会横向溢出。对象表 ≤5 列、态射表 ≤5 列。
- **绝对本地路径不得出现在交付物里**。`00_INDEX.md` 与各报告内只用相对路径引用。

## 非协商项（Non-Negotiables）逐条自查

| 条目 | 本技能如何满足 |
| --- | --- |
| 标题必须贴合用户领域与结果 | 标题用「对象表」「态射表」「范畴论重述」等领域词，不用「第一部分 / 分析结果」 |
| 表格只用于比较 | 仅对象表、态射表、极限清单、可证伪性表；其余用列表 |
| 引用不打断阅读 | 出处页码写成行内「(p.422)」，不设脚注区 |
| 视觉证据必须真实、可溯源 | Mermaid 图必须由报告自身数据画出；禁止贴占位图、示意图、装饰图 |
| 最终产物不含绝对本地路径 | 已约定；门禁不检查，人工复核 |
| 窄宽可读 | 表格 ≤6 列；Mermaid ≤12 节点 |
| 设计令牌命名一致 | 标注统一用 `【显式】/【半显式】/【重构】`；置信度统一用 `★` 五星制 |

## 交换图的特殊约束

Mermaid 是本产物唯一的「图形证据」，因此单独定规：

- 所有节点标签加引号，避免 `#` `:` `(` 导致解析失败
- 换行用 `<br/>`，不用真实换行
- 单图 ≤12 节点，超出则拆成多图
- 深色主题可读：显式设 `classDef` 填充色，不依赖默认样式
- **降级路径必须存在**：图渲染不确定时，用文字交换图（箭头 + 复合式）等价表达，两者任选其一即可满足门禁

## 复核者视角（Reviewer Rule）

复核者应同时看到「预期视觉方向」和「最可能让它显得低质的问题」：

| 最可能显得低质的问题 | 已配的防线 |
| --- | --- |
| 表格行数达标但内容注水 | 门禁粗判 ≥6 行 + 人工复核要求对象表 ≥8 行、态射表 ≥12 行 |
| 术语堆砌、读起来像术语替换游戏 | 通俗摘要章节强制「零范畴术语」 |
| 图渲染失败变纯文本 | 围栏配对断言 + 文字交换图降级路径 |
| 四轮报告长得一模一样 | 迭代规则 + 收敛轮强制「四轮演化记录」 |
| 引用页码是编的 | 人工抽查 3 条 |
