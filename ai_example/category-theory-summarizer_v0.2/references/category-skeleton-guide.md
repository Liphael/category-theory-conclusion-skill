# 范畴骨架抽取指南

> 沉淀自真实案例：APH413《Advanced Methods in Biostatistics》Week 1–4 讲义（209 页，频率派统计推断）。
> 该材料字面范畴论含量为 0%，但抽出了「一个单子、三对伴随、两次分解、五条极限」的完整骨架。
> 本文把该类任务中**反复出现**的模式固化下来，避免每份材料从零摸索。

---

## 一、应用类文本中，什么通常显式、什么通常需重构

这是最有用的一张表。应用类（统计 / 机器学习 / 工程文档）文本的规律高度一致：

| 结构 | 通常是否显式 | 说明 |
| --- | --- | --- |
| 对象：输入空间、输出空间、参数空间 | **显式** | 材料一定给名字（样本空间、参数空间、特征空间） |
| 态射：具体变换（随机变量、统计量、模型） | **显式** | 「X 是一个从样本空间到实数的函数」这类话常出现 |
| 复合：多步流程 | **半显式** | 材料会分步讲，但不会说"这是复合" |
| 恒等：id | **半显式** | 常以「回到原处」「等于自身」「无偏」等形式出现 |
| 函子 | **重构** | 几乎从不出现 |
| 自然变换 | **重构**（个别显式） | 「A 与 B 是同一件事的两种写法」常是自然同构的口语版 |
| 极限 / 余极限 | **重构** | 但实例极多（见第三节） |
| 伴随 | **重构** | 但 Galois 型（对偶、双向对应）经常被材料显式陈述 |
| 单子 | **重构** | 几乎从不出现，但"取某种平均/汇总"常是代数映射 |
| Yoneda | **通常不适用** | 见第五节 |

**方法论结论**：应用类材料的范畴化，**绝大部分工作量在「把材料已在做的事命名出来」**，而不是引入新结构。报告的诚实度取决于有没有把这件事说清楚。

## 二、常见单子与"汇总"操作

**经验规律**：材料里但凡有「把一堆东西合并成一个东西」的操作，先怀疑它是某个单子的乘法 μ；但凡有「取平均 / 取期望 / 取汇总值」的操作，先怀疑它是代数映射 α。

| 材料的说法 | 可能的单子 | 单位 η | 乘法 μ | 代数映射 α |
| --- | --- | --- | --- | --- |
| 分布、抽样、随机性 | **Giry 单子** $P$（on Meas） | Dirac $\delta_x$ | 混合 / 积分 | 期望 $\mathbb{E}:P(\mathbb{R})\to\mathbb{R}$ |
| 集合/幂集、非确定性 | 幂集单子 | 单元素集 | 并集 | 属于关系的特征 |
| 列表、序列、多样本 | List / 自由幺半群单子 | 单元素列表 | 连接（flatten） | fold |
| 可能失败、可选值 | Maybe 单子 | Just | 展平 | 默认值 |
| 带副作用的计算、状态 | State / IO 单子 | 纯值注入 | 副作用串联 | 运行器 |

**验证单子的三条自查**（不要看到"汇总"就下单子结论）：

1. 单位律在材料里有对应陈述吗？（例：$\mathbb{E}[c]=c$，材料会说"这是固定常数"）
2. 乘法律在材料里有对应陈述吗？（例：全期望公式——**很多材料没有**，那就标信息缺失）
3. 代数映射是幂等的吗？（例：$\mathbb{E}^2=\mathbb{E}$，因为期望是常数）

## 三、极限与余极限在应用文本中的常见藏身处

**经验规律**：应用文本不写"极限"二字，但下面这些说法几乎必是极限/余极限。

| 材料的说法 | 范畴结构 |
| --- | --- |
| 「同时考虑 / 联合 / 成对」、多个副本 | **乘积** $A\times B$；单oidal 情形为 $A\otimes B$ |
| 「独立」「联合等于边际之积」 | **⊗-可分性**（Markov 范畴中的独立性定义） |
| 「i.i.d.」「独立同分布」 | 采样态射沿 $\mathrm{copy}_n$ 与 $m^{\otimes n}$ **分解** |
| 「满足某条件的全体」「逆像」「满足不等式者」 | **拉回 / 逆像** $f^\*(S)$ |
| 「解方程组」「令两者相等后求解」 | **等化子 / 核**（常以约束形式出现） |
| 「对称函数」「与顺序无关」 | **余等化子**（对对称群作用的商） |
| 「把总变异拆成 A + B」「分解为两正交部分」 | **双积 $\oplus$**（同时是积与余积） |
| 「投影」「分量」「正交补」 | **分裂幂等**（Karoubi 分裂） |
| 「残差」「剩下的部分」「不能由 A 解释的」 | **余核 / 正交补** |
| 「至少一个成立 / 至少有一个不同」 | 格中的**余积（并）** |
| 「随着 n 增大趋于……」「大样本下近似」 | **分析极限**（不是范畴极限，但必须单独列一类） |

**必须区分两类极限**：范畴极限（乘积、拉回、等化子……）与分析极限（收敛、渐近）。材料里两者常混着出现，报告里必须分开列，否则读者会混淆。

## 四、常见伴随与对偶

| 材料的说法 | 伴随 | 层级 |
| --- | --- | --- |
| 「自由构造 vs 遗忘结构」 | Free ⊣ Forgetful | Cat 严格 |
| 「A 与 B 一一对应，且反向单调」 | Galois 连接 | **Pos 严格** |
| 「区间估计 ↔ 假设检验」 | 置信集 ⊣ 接受域 | **Pos 严格**（Casella–Berger 对偶） |
| 「拒绝域 ↔ 显著性水平」 | 拒绝域 ⊣ 阈值 | Pos 严格 |
| 「正交补」「互为正交补」 | $(\perp)\dashv(\perp)$ | Pos 反序自伴随 |
| 「像 / 逆像」 | $\exists_f\dashv f^\*\dashv\forall_f$ | Pos 严格（子对象格） |
| 「内积中的转置 / 伴随算子」 | $f\dashv f^\dagger$ | dagger |
| 「正推与反推」「前向与反向」 | **先怀疑是伴随，再验证** | 待定 |

**$\exists_f\dashv f^\*\dashv\forall_f$ 特别好用**：材料里凡是「沿某个映射 f 往前推」和「沿 f 往回拉」成对出现，就检查这一对。
典型：统计量 $t$ 的**抽样分布**（$=\exists_t$ 像）与**拒绝域**（$=t^\*$ 逆像）是同一对伴随的两端，由恒等式 $(t_\*\mu)(T)=\mu(t^\*(T))$ 相连。

## 五、Yoneda：什么时候能写，什么时候只能放弃

**完整 Yoneda 引理需要**：预层范畴、可表示函子。应用类文本几乎全都没有。

**能写的（且可严格证明）**：

1. **探针分离性**：对象由射向它的探针族决定。线性代数版本——向量由一切线性泛函决定；应用文本版本——"总体参数由一切统计量/对照决定"。
2. **可识别性 = 模型探针映射的单性**：材料说"加约束以保证可识别"，就是在说"让参数→分布的映射成为单射"。

**只能放弃的**：Yoneda 引理本身、可表示函子、米田嵌入的泛性质。此时写明「完整 Yoneda 无着力点，原因：无预层结构」，放进「信息缺失」。

**一个反直觉但有用的观察**：推断类材料的困难，恰恰在于**做不到** Yoneda——看不到对象的全部探针。而像"枢轴量"这类构造之所以珍贵，正因为它把一条依赖参数的探针族**坍缩**成了与参数无关的量，是 Yoneda 的**反向操作**。这类观察能显著提升报告的深度，但必须标注为「解读」而非「结构」。

## 六、学科切入点速查

| 学科 | 先找什么 | 常见基范畴 | 常见主线复合 |
| --- | --- | --- | --- |
| 统计 / 推断 | 参数空间、样本空间、统计量 | Meas + Giry 单子；Kl(P)=Stoch | 参数 → 样本分布 → 统计量分布 → 参数 |
| 机器学习 | 数据空间、模型空间、损失 | Vect / 微分范畴 / 光学元件演算 | 数据 → 特征 → 预测 → 损失 |
| 编译 / 程序语言 | 语法范畴、语义范畴 | Cat（语法）→ 语义域 | 语法 → AST → IR → 目标码 |
| 并发 / 分布式 | 进程、消息、事件 | 迹范畴 / 事件结构 / 双图 | 局部事件 → 全局迹 |
| 数据库 | 模式、实例、查询 | 表代数 / 函子数据模型 | 模式 → 实例 → 查询结果 |
| 物理 / 量子 | 系统、过程 | 紧闭范畴 / 过程理论 | 制备 → 演化 → 测量 |
| 控制 / 系统 | 状态、输入、输出 | 信号流图 / 双图 | 输入 → 状态演化 → 输出 |

## 七、三条防过度声称的自查

1. **伴随层级标了吗？** 没标层级的"伴随"声明一律视为未标注，必须补
2. **有没有把类比当严格？** 「看起来像函子」和「是函子」必须分开写
3. **重构条目有没有指回材料？** 指不回的就是重构，不能写成显式
